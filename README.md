# mhxy_keju(梦幻西游)

截取游戏界面的题目 → OCR 识别 → 题库匹配 → 语音播报答案。

只读取屏幕像素,不读写游戏进程与内存;答案由你自己点击。

本应用是从 `keju-answerer` 里抽出的**科举单功能版**:去掉了工具箱那层窗口,
启动直接进答题器;降妖伏魔(地图找点)不在本应用里。

## 运行

源码运行(开发/调试):

```bash
.venv\Scripts\python keju.py
```

打包版:`dist\mhxy_keju\mhxy_keju.exe`,双击即用(首次运行会把内置题库与
语音缓存复制到程序目录)。

## 使用

1. 打开游戏(别最小化),把游戏分辨率设成最小的那档 **640×480** —— 整窗口截图
   OCR 最快,实测答题响应中位 0.32s
2. 启动本应用就完事:自动找到每个客户端窗口、把整个窗口设成题目对话框
   (多开各占左栏一个名字框,最多 **5 个**,多出的舍弃),**自动监听默认开启**,
   题库在**每天首次启动**时后台自动更新 —— 换题即自动识别并播报;
   界面正中就是**当前题目 + 大字答案**

识别模式用右上**「御前科举」**单按钮切换(文案=当前模式,点一下切「三大学士」,
再点切回来):

| 模式 | 适用 | 判定 |
| --- | --- | --- |
| **御前科举**(默认) | 带"御前科举大赛第X关…题目:"的对话框 | 只认这种对话框 |
| **三大学士** | 三大学士等答题界面(深色弹窗,没有对话框头) | 不看对话框头,直接匹配题干 |

跟界面有关的约定:

- 每个客户端在左栏是一个**角色名框**(名字抠自客户端窗口标题;还没进角色
  的窗口没有名字,显示「客户端N」);框上的 **×** 把那一台从定位里删掉
- **关闭应用会清空所有坐标**;下次启动重新自动定位
- **挪动过客户端、或改过游戏分辨率会自动跟随**;不对劲就点一次左栏的
  **【客户端刷新】**(整行重新自动定位;删剩的客户端不会自动补回)
- 右上一排文字钮:**手动识别**(立刻识别一次,自动监听关着也能用)、
  **迷你置顶**(置顶大字显示最近答案)、**播报试听**、**语音静音**
  (静音后文案变「语音恢复」);题目卡右上角的**「换肤」**小钮一键在
  **玄夜(深色)** / **玄白(浅色)** 两套皮肤间切换,选择会记住
- **收益**仍在后台自动统计 **银两 / 经验 / 物品**(按天清零,存
  `data/rewards.json`),界面上不显示,用命令行 `--rewards` / `--stats` 看;
  题库每天首次启动自动更新一次(当天再启动不重复更新)

## 命令行

```bash
python keju.py --selftest [--seed N]   # OCR+匹配自检(合成图片)
python keju.py --stats [--since HH:MM] # 命中率/漏答构成 + "题目出现→答案"耗时
                                       # (读 data/events.jsonl;老数据回退解析日志)
python keju.py --rewards               # 看今天的答题收益(银两/经验/物品明细)
python keju.py --uncollected           # 列出疑似题库未收录的读法(含当屏选项)
python keju.py --uncollected 1=常建    # 直接把第 1 条的答案补进题库
python keju.py --update-bank           # 检查并更新题库
python keju.py --build-voice-cache     # 预合成全部答案音频(4 路并发)
python keju.py --tts-test              # 语音测试
python tests.py                        # 回归测试(全量;--fast 快速模式)
```

## 打包

双击 `package.bat`(或 `.venv\Scripts\python.exe package.py`),产出两个东西:

- `dist\mhxy_keju\` —— 绿色目录版,双击 exe 即用(首次运行会把内置题库与
  语音缓存复制到程序目录)
- `dist\mhxy_keju_v1.0.0.exe` —— 安装包,双击装到
  `%LOCALAPPDATA%\Programs\mhxy_keju`(每用户安装,不需要管理员),
  出桌面/开始菜单快捷方式,完成页可直接启动应用;控制面板「应用与功能」
  可卸载,卸载保留配置/题库/收益记录。安装包不带开发机的运行时产物
  (配置/日志/收益/事件),新用户首次启动自动生成默认配置

打包前会关掉正在运行的旧 exe,并把 `dist` 里的 `config.json`、日志、收益
记录备份出来,打完再放回去;`--dry-run` 只看会保留哪些文件。
只重出安装包不重打 exe 用 `--installer-only`,只出绿色版用 `--no-installer`。

安装包用 Inno Setup 6 压制(没有就 `winget install --id JRSoftware.InnoSetup -e`,
没装时脚本会在绿色版打好后报错提示;单独手动跑 spec 无图标属正常,图标由
package.py 用窗口同款状元帽绘制代码现生成到 `installer/app.ico`,连同中文
向导语言包 `installer/ChineseSimplified.isl` 都不入库、打包时自动备齐)。

## 代码结构

| 文件 | 作用 |
| --- | --- |
| `core.py` | 地基:配置 / OCR / 截图 / 语音 / 窗口枚举 / 识别引擎调度 |
| `cli.py` | 命令行:`--selftest` / `--stats` / `--uncollected` / `--rewards` 等 |
| `bank.py` | 题库子系统(题库数据、匹配、官方源更新) |
| `gui.py` | 单窗口应用的生命周期 + 各按钮回调 |
| `ui/` | 界面构建(主窗 / 迷你窗)与主题动效 |
| `tools/keju.py` | 科举自己的状态/线程/循环(识别、收益统计、事件落盘) |
| `keju.py` | 入口(argparse + 命令行分支) |
| `data/keju_questions.json` | 题库(可手工补题,更新只加不减) |
| `data/events.jsonl` | 识别事件(逐条 jsonl,`--stats` 的数据源) |
| `voice_cache/` | 答案音频缓存(参数变更后自动清理) |
| `config.json` | 配置(区域/间隔/阈值/识别模式等,首启生成) |

## 提醒

使用第三方辅助工具可能违反游戏用户协议,风险自担;本工具不自动作答,仅播报答案。
